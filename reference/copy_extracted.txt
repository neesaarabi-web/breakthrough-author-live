TECHNICAL NOTES FOR GHL BUILD:
DOM Transplant:
• Same technique as BAM landing page
• JS document.body.appendChild(wrap) on load
• Hide empty GHL shell after
• All GHL element padding/margin set to 0px before pasting code
CSS Selector IDs needed:
• Section, Row, Column, and Custom Code element IDs from GHL editor
• Conﬁrm all padding/margin zeroed in GHL Styles panel
Responsive:
• Mobile-ﬁrst design
• Two-column sections (case studies, for/not for) stack to single column on mobile
• Buy button sticky on mobile or repeated after every section
• Video section should be full-width on mobile
Checkout:
• Shows $950 as price
• Coupon code ﬁeld visible
• Code [CODE] drops to $47
• One-click checkout if possible
Retargeting pixel:
• Facebook pixel on page
• Track: PageView, ViewContent, InitiateCheckout, Purchase
• Build retargeting audiences from page visitors who don't buy
For glows/visual effects:
• Use position:absolute divs with border-radius:50% + ﬁlter:blur()
• CSS radial-gradient renders as solid blocks in GHL — avoid
